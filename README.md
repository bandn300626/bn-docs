# B&N documentation

Public guides for B&N scripts, published with GitHub Pages on every push to `main`.

- `yarn build` and `yarn serve`: see the site locally, search included.

## Adding a script

1. Put its pages in `docs/<id>/`, with a `README.md` as its first page.
2. Add it to `scripts.js`: the menu, the sidebar and the home page read from there.
